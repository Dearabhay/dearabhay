# Abhay Kumar Portfolio Website

This is a separate React + Vite portfolio website for Abhay Kumar.

## Run locally
npm install
npm run dev

## Deploy on Vercel
1. Upload this folder to GitHub.
2. Open Vercel.
3. Add New Project.
4. Import the GitHub repository.
5. Click Deploy.

## app-ads.txt
After deploy, check:
https://your-domain.vercel.app/app-ads.txt
